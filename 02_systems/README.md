# 02_systems — RPG Core Systems

Canonical data registries for The Veil's interactive RPG mechanics:

- `items.json` — Symbolic objects, equipment, keys, and consumables (bridged with `12_metaphysics/symbolic_object_registry.json`).
- `quests.json` — Main narrative arc, district unlock quests, and side quests with False vs. True Ending paths.
- `encounters.json` — Resonance Trials & Quasar Gravity Tests (psychometric RPG checks).
- `economy.json` — Echo currency, merchant inventories, and barter rules.
