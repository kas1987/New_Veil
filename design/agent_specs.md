# Veil/999 Lore Agent Specifications

## Lore Expansion Agent
- Input: Persona ID, branch relationships, theme/flaw prompt
- Output: Rich backstory, motivations, secrets, echo connections, "reflection" text

## Scene/Dialogue Generator Agent
- Input: Event type (intro, conflict, revelation), persona context, player state
- Output: Branching scene text, dialogue stubs, echo/whisper variants

## Branching Pattern Analyzer Agent
- Input: Current branch structure, curiosity/event logs, progression stats
- Output: Recommendations for nexus events, new echo branches, underused areas

## Cross-Arc Echo Agent
- Input: Completed branches, trust/curiosity, prior events
- Output: Suggested cross-arc connections, environmental/meta echo triggers
