# Quasar Truth

The Dark Quasar is the deep truth of the Veil — the gravitational reality
that the Prism surface conceals. It is not evil. It is not punishment.
It is the weight of being truly known.

## The Pull

The Quasar pulls the worthy closer. This is not metaphor. In the simulation,
the `DarkQuasar.apply_gravity()` method increases suspicion and decreases
affection in proportion to how much TRUST has been built.

This is the "no easy wins" mechanic: trust that grows too comfortable
attracts disruption. Not because trust is bad, but because trust that
has never been tested is not yet trust — it is merely assumption.

## What the Quasar Reveals

- Hidden paths that only appear during quasar_active state
- True names (including Mira's true name, Thesmera Locke)
- The fact that the Prism is a partial truth
- The depth of other agents' hidden functions
- The Veil state cycle itself

## What the Quasar Demands

To survive quasar_active and emerge with trust intact, a player must:
1. Have built genuine resonance (> 0.6) before the Quasar activates
2. Recognize that the disruption is testing, not punishment
3. Maintain emotional depth even when signals are distorted
4. Not retreat to surface-level interaction (this guarantees false endings)

## The Transformation

If a player endures quasar_active and maintains trust, the transformation is:
- Suspicion decreases (the test was passed)
- Affection stabilizes (the bond was earned)
- Hidden paths open (the Veil recognizes depth)
- True names become speakable (the membrane thin enough)

If a player fails:
- Affection sags permanently
- Trust drops
- The Quasar's gravity reinforces the surface
- The player is pushed back toward Prism-level interaction

This is the core loop of Veil Town: surface comfort → hidden pull → test → earned depth.

## Quasar in Code

The Quasar is not just lore. It is implemented:
- `veil_effects.py`: `DarkQuasar.apply_gravity(state, excess)` — the actual mechanic
- `veil_effects.py`: `VeilStateMachine` — the cycle that activates it
- `scorer.py`: Alignment scoring that detects Quasar-appropriate content
- `unlock_engine.py`: District unlocking that requires Quasar-tested resonance

The Quasar is as real as the code that implements it.
