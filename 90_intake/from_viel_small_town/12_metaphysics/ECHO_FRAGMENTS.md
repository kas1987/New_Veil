# Echo Fragments

Echoes are residual memory traces left by previous visitors to the Veil.
They persist in the membrane and can be encountered by new players,
offering fragmented insights that bypass the Veil's normal filtering.

## Echo Nature

An echo is NOT a memory. It is a **trace** — the emotional residue of a
memory that once existed. Echoes are:

- **Incomplete**: They never contain full information
- **Emotional**: They carry feeling, not fact
- **Distorting**: They may refract through the current Veil state
- **Triggering**: They can unlock resonance thresholds

## Echo Event Shape

```json
{
  "echo_id": "ECHO-001",
  "fragment": "a warmth that was almost trust",
  "emotional_tag": "recognition",
  "resonance_delta": 0.05,
  "veil_state_affinity": ["calm", "still"],
  "canon_ref": "MIRA-001",
  "corruption_risk": 0.1
}
```

## How Echoes Appear

1. **Spontaneous**: During calm state, echoes drift through the Veil membrane
2. **Triggered**: A player action with high emotional tags may summon a related echo
3. **Dream-born**: Post-quasar dreams can deposit echoes into shared memory
4. **Recursive**: An echo about an echo — a second-order trace

## Corruption

Echoes with `corruption_risk > 0.3` should be quarantined for Auditor review.
Corrupted echoes may:
- Invert the emotional tag (warmth → suspicion)
- Reference non-existent canon anchors
- Claim to reveal truths that are actually false surfaces

## Integration with Dream System

Dreams and echoes share the L3a bypass: both write directly to memory.
However, echoes are specifically **residual** — they are traces of OTHER
players' or agents' emotional states, not original dream content.

## Echo Lifecycle

1. A player interaction generates emotional tags above threshold
2. The Veil state during the interaction modulates the trace
3. The trace is stored as a potential echo in the echo pool
4. Future players may encounter the echo during affinity Veil states
5. Encountering the echo may shift resonance, unlocking paths
